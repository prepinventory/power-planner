# Power Runtime Planner

A free backup-power runtime calculator from [The Blackout Brief](https://blackout-brief-c7dc37.beehiiv.com/).

One static page (`index.html`). Nothing a visitor enters is stored or sent anywhere.

## Solar Panel Compatibility Checker

`solar-checker/index.html` checks whether solar panels can safely connect to a battery or power station's solar input (cold-weather Voc, amps, watts, daily refill). Also a single static page that stores nothing.
